# Рилсы Яны — каталог

**[Открыть сайт](https://iefymv.github.io/iana-reels-catalog/)** · [Читать текстовую версию](catalog.md) · [Таблица CSV](catalog.csv) · [Скачать комплект](iana-reels-transcripts.zip)

86 карточек по роликам профиля [iana.bestcredit4you](https://www.instagram.com/iana.bestcredit4you/reels/).

В каждой карточке: рабочее название, ссылка на источник, структура сценария, текст речи, описание публикации, хештеги, опорные кадры и план съёмки/монтажа. Тексты и SRT также доступны в отдельных файлах.

Распознавание речи выполнено автоматически локальной моделью Whisper large-v3-turbo. Написание очевидных кредитных терминов нормализовано; имена, числа и даты требуют сверки с оригиналом. Полная ручная проверка на слух не проводилась. Утверждения из роликов переданы как исходный материал, а не как проверенные рекомендации.

Названия и сценарная структура составлены для навигации. Визуальная часть проверена по шести опорным кадрам каждого видео. Инструкция по монтажу — редакционный план пересъёмки; точные микросклейки и звуковые эффекты не размечены.

Музыкальные нарезки и внешняя игровая сценка описаны через визуальный сценарий. У одного скачанного ролика нет аудиодорожки; это отмечено в карточке.

Сайт статический, без аналитики и внешних библиотек. Изображения встроены в HTML. Исходные видео не загружены в репозиторий; ссылки ведут на Instagram.
